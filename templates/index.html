About the Project

AI Career Pulse: Decoding the Job Market

Project Overview

This project analyses AI job market trends using Tableau Public. The dashboard provides insights into salary distribution, experience requirements, company size, employment type, remote work opportunities, and the most in-demand AI skills.

The goal is to help students, job seekers and professionals understand hiring trends and make informed career decisions using data visualization.
